# Unit selector at `0x80052F9C`

The production C source matches the complete 324-byte routine. It searches
three linked lists whose heads begin at context offset `0x78`.

Passing no previous unit, or a unit without flag bit one, starts at head zero.
Otherwise traversal resumes at that unit's next pointer (`+0x04`) and its
unsigned list slot (`+0xA0`). An exhausted list advances through the remaining
heads while the slot is less than two. Slots outside that range do not cause
another head lookup.

Candidates must contain every requested flag bit at `+0x218`. A zero mask
therefore accepts any flag word. When the final argument is nonzero, a candidate
must also pass `func_80047688`; otherwise that eligibility call is skipped.
The first accepted candidate is returned, or null when traversal is exhausted.

Two inline traversal helpers retain the retail's different initial-index
registers, `a2` for the first lookup and `a1` for subsequent lookups. The fixed
register is only a short-lived carrier; the loop's counter remains an ordinary
unsigned variable so the compiler can retain the retail induction-pointer
updates. The empty constraints emit no instructions.

Layout assertions enforce the accessed `0x21C`-byte unit prefix and
`0x84`-byte context prefix, including their 32-bit pointer fields. These are
prefix views rather than claims about complete object sizes. The emitted
section includes 12 bytes of zero padding after the routine.
