# Raw-unit recovery candidate batch

This batch preserves compiler-valid semantic C recoveries for 21 functions that
remain raw instruction wrappers in the matching build.  Together they cover
3,932 bytes of retail code.  Low-level context-switch trampolines at
`0x800940B4` and `0x80094AFC` are deliberately excluded because their available
drafts only restate the original instructions as inline assembly.

Run `make verify-research-candidates` to compile every tracked candidate with
the project's matching toolchain and compare its generated bytes with the
corresponding retail executable range.  A compiling candidate is not counted
as matching progress until that comparison reports `EXACT`; the raw source
wrapper remains authoritative in the normal build until then.

The batch includes grid-link maintenance, controller and stream state,
callback dispatch, CD-ROM/DMA setup, memory routines, and kernel-facing support
code.  Keeping these candidates under version control makes their recovered
control flow reviewable and prevents subsequent matching work from restarting
from raw instructions.
